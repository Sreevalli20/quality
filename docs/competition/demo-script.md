# Demonstration Script — ≈2.5 minutes

Live app: https://quality-gyfoxhaaazq8o5appxggj.streamlit.app/
(replace with the current Streamlit Cloud URL)

## 0:00–0:15 — Hook (Home)

> "Every winter we hear 'the air is bad, stay indoors.' AirAware AI turns
> that vague warning into a personal plan. Watch."

Point at the hero: *Breathe smarter. Live better.* Mention it works with
no API key and no account.

## 0:15–0:40 — Get a reading (Home → Explorer)

Click **Enter my own numbers**, type PM2.5 = 150, PM10 = 280, click
**Assess my air quality**.

> "AQI is the *maximum* pollutant sub-index — one bad pollutant sets the
> whole number. See how PM2.5 dominates."

Show the gauge, dominant pollutant chip, data-completeness meter, and
the pollutant cards.

## 0:40–1:05 — The differentiator (My Daily Air Plan)

Navigate to **My Daily Air Plan**.

> "This is what makes AirAware different: a 24-hour planning outlook.
> Likely AQI category per time window — not fabricated hourly numbers,
> clearly labelled estimates with a confidence grade."

Point at the best-window card and the window-by-window table: walk,
exercise and sport verdicts per window plus ventilation advice.

## 1:05–1:30 — Personalised advice (Personal AI Assistant)

> "Now make it about *your* life."

Fill a few profile fields quickly (city, transport = bike, household =
children), submit. Show prioritised advice cards — what / why / when /
cost / alternative. Ask a follow-up in the chat: *"What's the best time
to go for a run?"* — answer is labelled **rule-based** (or AI if a key
is configured; say so honestly).

## 1:30–1:50 — Protect the home (Indoor Air Guardian)

Pick the **Bedroom**, compare one budget tier, show ventilation advice
keyed to today's AQI.

> "On a Poor-or-worse day the app says keep windows closed and recirculate
> — timing matters more than gadgets."

## 1:50–2:15 — Choices → impact (Lifestyle → Impact)

**Green Lifestyle Planner**: shortlist one swap ("I'll try this").
**Environmental Impact**: log a metro-instead-of-car trip, show the
CO₂e saved and the assumptions expander.

> "Every swap shows honest trade-offs — benefits *and* limitations.
> The impact page turns choices into numbers."

## 2:15–2:30 — Close (Family & About)

**Family & Community**: checklist progress + kid-friendly explainer.
**About & Data Sources**: CPCB methodology, provider status, build
stamp, honest limitations.

> "Measurement → understanding → advice → plan → action → impact →
> report. AirAware AI: breathe smarter, live better."

## Fallbacks

- If asked about forecasting: "CPCB publishes no public hourly
  forecast, so the outlook is a labelled planning estimate — diurnal
  model plus your session trend, with confidence grading. We never
  fabricate readings."
- If asked about AI: "Gemini is optional via provider abstraction;
  every response is labelled AI vs rule-based, and the app works fully
  without a key."
